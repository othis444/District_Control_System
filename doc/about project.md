# 📋 منظومة إدارة الكنترول والرصد السري

<p align="center">
  <b>منظومة ويب متكاملة (Offline-First) لمديريات التربية والتعليم لمعالجة بيانات الطلاب الضخمة وإصدار كشوفات الرصد والتقارير بدقة وبسرعة فائقة.</b>
</p>

---

## 🎯 فكرة النظام

**منظومة إدارة الكنترول والرصد السري** هي تطبيق ويب متكامل يعمل بالكامل داخل متصفح المستخدم (**Offline-First**) دون الحاجة لأي خادم خارجي أو اتصال بالإنترنت. 

تستطيع المنظومة معالجة بيانات الطلاب الضخمة (أكثر من **20,000 طالب**) وتُنتج كشوفات الرصد السري والتقارير العامة بضغطة زر، مع الحفاظ على **الخصوصية الكاملة للبيانات** حيث لا يتم رفع أي بيانات خارج جهاز المستخدم.

---

## 🏗️ البنية المعمارية والتقنيات المستخدمة

| المكوّن | التقنية | الدور |
| :--- | :--- | :--- |
| **الواجهة** | HTML5 + CSS3 + Bootstrap 5 RTL | تخطيط عربي متجاوب واحترافي |
| **المنطق (Logic)** | JavaScript ES6+ (Vanilla) | معالجة كاملة للبيانات داخل المتصفح |
| **قراءة الإكسل** | SheetJS (XLSX) | استيراد ملفات البيانات الضخمة محلياً |
| **الرسوم البيانية** | Chart.js 4 | إحصائيات تفاعلية وتحليلات بصرية |
| **الأيقونات** | Font Awesome 6 | واجهة بصرية غنية ومفهومة |
| **الخطوط** | Cairo (Google Fonts) | طباعة عربية واضحة ومناسبة للمستندات الرسمية |

## 🔑 المكونات الوظيفية الرئيسية

### 1️⃣ وحدة استيراد البيانات الذكية
* **كشف تلقائي ذكي للأعمدة** من ملف الإكسل عبر محرك بحث بالكلمات المفتاحية:
  * `الرقم السري` / `Secret` / `سري`
  * `HVZMQ` / `كود رقم الجلوس` / `كود الجلوس`
  * `رقم الجلوس` / `الجلوس`
  * `اسم الطالب` / `الاسم` / `Name`
  * `اسم المدرسة` / `المدرسة`
  * `الصف` / `Grade` / `Class`
  * `النوع` / `الجنس`
* **كشف الأعمدة الإضافية تلقائياً** (المواد الدراسية: القرآن، التربية الإسلامية، الرياضيات، العلوم...) وإتاحتها للطباعة.
* **دعم السحب والإفلات (Drag & Drop)** لسهولة وسرعة رفع الملفات.
* **قراءة ورقة `studentnumbers`** تحديداً مع التراجع الذكي لأول ورقة إن لم تُوجد.
* **شريط مؤشر للجودة** يعرض الحقول المكتشفة بعد التحميل مباشرة.

### 2️⃣ وحدة فحص جودة البيانات
* كشف **الأرقام السرية المكررة** فوراً لتفادي الأخطاء.
* تحديد **الطلاب بدون رقم سري** أو **بدون مدرسة** أو **بدون صف**.
* عرض التحذيرات بألوان دلالية (خطر 🔴 / تحذير 🟡 / معلومة 🔵).

### 3️⃣ وحدة الإحصائيات والتحليل
* **بطاقات KPI ثلاثية**: (عدد المدارس / عدد الطلاب / عدد الصفوف).
* **رسوم بيانية تفاعلية** (Chart.js):
  * توزيع الطلاب حسب الصف (أعمدة رأسية).
  * أكبر 15 مدرسة من حيث عدد الطلاب (أعمدة أفقية).
* **بطاقات تفصيلية للصفوف** مع إمكانية التصفية الفورية.
* **ارتفاع ثابت للرسوم (300px)** لمنع التمدد المزعج أثناء التصفح.

### 4️⃣ وحدة عرض المدارس المُحسّنة
* **بطاقات أنيقة لكل مدرسة** تعرض:
  * اسم المدرسة + عدد الطلاب الإجمالي.
  * **أشرطة أفقية متدرجة الألوان** لكل صف دراسي (لتوضيح التوزيع بصرياً).
  * **بحث فوري** باسم المدرسة.

### 5️⃣ وحدة كشوفات الطباعة (قلب النظام)

#### 🅰️ وضع "كتل الأرقام المتكررة" (مناسب للرصد اليدوي بالدرجات)
| الخاصية | المدى التكيفي |
| :--- | :--- |
| **عدد الكتل / صفحة** | 3 ← 6 |
| **عدد الصفوف / كتلة** | 25 ← 50 |
| **سعة الصفحة الواحدة** | تصل إلى **300 رقم سري** |
| **أعمدة الكتلة** | 1 ← 5 (تحكم كامل بالحقول والعروض) |

#### 🅱️ وضع "الجدول العام" (مناسب للكشوف الكاملة)
* **تحكم كامل بالأعمدة**: إضافة / حذف / ترتيب / إعادة تسمية.
* **حساب ذكي للعروض (Smart Column Widths)**: يعتمد على طول المحتوى الفعلي × نوع الحقل × الأولوية.
* **متحكم أولوية لكل عمود**: (ضيق / تلقائي / عادي / واسع).
* **التفاف ذكي للترويسة** بينما تبقى البيانات في سطر واحد (`nowrap`).
* **خيار عمودين متجاورين** لتوفير استهلاك الورق.

### 6️⃣ وحدة الفلترة والبحث المتقدم
| الفلتر | الوظيفة |
| :--- | :--- |
| **المدرسة** | قائمة منسدلة + تحديث تلقائي للصفوف التابعة لها |
| **الصف** | يتغير ديناميكياً حسب المدرسة المختارة |
| **البحث النصي** | بحث سريع بالاسم / الرقم السري / كود الجلوس / رقم الجلوس |
| **الترتيب** | حسب (الرقم السري ↑↓ / الاسم / المدرسة / الصف / الترتيب الأصلي) |
| **النطاق الرقمي** | تحديد رقم البداية + عدد الطلاب (لطباعة أجزاء محددة من الكشف) |

### 7️⃣ وحدة التحكم بالطباعة والتصدير
* **تخصيص الترويسة**: (المديرية / المادة / عنوان الكشف / العام الدراسي).
* **تخصيص التذييل**: ثلاث خانات للتوقيع والاعتماد (يمين / وسط / يسار).
* **ضبط الأبعاد**: حجم الخط (9-14px) + ارتفاع الخلية (18-30px).
* **مؤشر A4 ذكي**: 
  * 🟢 **أخضر**: مناسب تماماً للصفحة.
  * 🟡 **أصفر**: مضغوط قليلاً.
  * 🔴 **أحمر**: تجاوز حدود الصفحة.
* **تصدير Excel**: تصدير البيانات المفلترة إلى ملف Excel منفصل بنفس الأعمدة المحددة.

## 🎯 سيناريوهات الاستخدام الفعلية

> **السيناريو 1: طباعة كشوف الرصد السري**  
> *"أريد 200 رقم سري في صفحة A4، موزعين على 5 أعمدة، كل عمود 40 صفاً، مع خانة فارغة لرصد الدرجة."*  
> 👉 **الخطوات:** اختر **وضع الكتل** ← 5 كتل × 40 صف ← عمودان (الرقم السري + فارغ) ← طباعة.

> **السيناريو 2: طباعة كشف عام كامل**  
> *"أريد كشفاً يحتوي على: الرقم السري، كود الجلوس، رقم الجلوس، اسم الطالب، المدرسة، الصف، وجميع الدرجات."*  
> 👉 **الخطوات:** اختر **وضع الجدول العام** ← حدد الأعمدة المطلوبة ← عدّل الأولويات ← طباعة.

## 🚀 نقاط القوة الجوهرية

1. **يعمل بلا إنترنت (Offline-First)**.
2. **لا يحتاج أي تثبيت** — ملف HTML واحد يعمل بفتحه مباشرة.
3. **آمن تماماً** — بيانات الطلاب الحساسة لا تغادر جهاز المستخدم أبداً.
4. **مرن ومبتكر** — يتعامل مع مختلف أشكال ومسميات ملفات Excel.

# District_Control_System
نظام ادارة اعمال الكنترول للمديرية مع فلاتر طباعة تقارير متقدمة وبالامكان تخصيصها اضافة الى الاحصائيات ويتعامل النظام مع بيانات في excel
# 🎯 منظومة إدارة الكنترول والرصد السري

> منظومة ويب متكاملة (Offline-First) لإدارة كشوفات الرصد السري وإصدار التقارير 
> الاحترافية لمديريات التربية والتعليم — تعمل بالكامل داخل المتصفح.

## ✨ المميزات الرئيسية

- 📥 **استيراد ذكي من Excel** — كشف تلقائي للأعمدة (الرقم السري، كود الجلوس، الاسم، ...)
- 📊 **إحصائيات تفاعلية** — رسوم بيانية + بطاقات KPI
- 🖨️ **وضعان للطباعة:**
  - كتل الأرقام المتكررة (لرصد يدوي لـ 200 رقم/صفحة)
  - الجدول العام (كشوف كاملة بجميع الأعمدة)
- 🎛️ **تخطيط ذكي للأعمدة** — عرض تلقائي حسب المحتوى
- 🔒 **خصوصية مطلقة** — لا رفع لأي بيانات خارج جهازك
- 🌙 **وضع ليلي/نهاري**
- 📱 **متجاوب** — يعمل على كل الأجهزة
